# AGENTS.md — intelbit-floweon-1c-extension

## Назначение репозитория

Расширение конфигурации 1С для **Интелбит.Фловеон**. Содержит BSL-код и XML-структуру объектов метаданных.

## Для AI-агентов

- BSL-код пишется на русском языке (конвенция 1С-экосистемы).
- XML-файлы — стандартный формат экспорта конфигурации 1С v8.3.24+.
- Скелеты в `src/` содержат `ВызватьИсключение "Не реализовано"` — реализация в Промпте 4-17-12.
- Правовые файлы (LICENSE/NOTICE/CONTRIBUTING) не трогать без явной инструкции.
- После изменений: не пушить — ждать команды «push» от Свята.

## Связанные репозитории

- `intelbit-floweon-connector-onec` — Python-клиент (~/Developer/)
- `intelbit-floweon-monorepo` — ядро Фловеона (~/Developer/)
