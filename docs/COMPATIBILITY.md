## Объекты метаданных

Расширение добавляет следующие объекты (не пересекаются с типовой конфигурацией):

| Тип объекта | Имя | Назначение |
|---|---|---|
| HTTPСервис | `intelbit_floweon` | REST API для Фловеона |
| Общий модуль | `ИнтелбитФловеонОбщие` | Утилиты: форматирование ответов, парсинг JSON |
| Общий модуль | `ИнтелбитФловеонАутентификация` | Проверка Bearer/Basic |
| Общий модуль | `ИнтелбитФловеонВебхуки` | Публикация исходящих событий |
| Общий модуль | `ИнтелбитФловеонEnterpriseData` | Работа с регламентными обменами |
| Регламентное задание | `ИнтелбитФловеонОтправкаВебхуков` | Фоновая отправка webhook-очереди |
| Регистр сведений | `ИнтелбитФловеонОчередьВебхуков` | Буфер исходящих webhook-событий |
| Константа | `ИнтелбитФловеонURL` | URL Фловеон-сервера |
| Константа | `ИнтелбитФловеонСекретWebhook` | Секрет HMAC |
| Константа | `ИнтелбитФловеонКлиентID` | OAuth Client ID |

Все имена объектов начинаются с префикса `ИнтелбитФловеон` — конфликты с типовой конфигурацией исключены.
