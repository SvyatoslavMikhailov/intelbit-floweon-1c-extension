## Объекты метаданных

Расширение добавляет следующие объекты (не пересекаются с типовой конфигурацией):

| Тип объекта | Имя | Назначение |
|---|---|---|
| HTTPСервис | `intelbit_river` | REST API для Реки |
| Общий модуль | `ИнтелбитРекаОбщие` | Утилиты: форматирование ответов, парсинг JSON |
| Общий модуль | `ИнтелбитРекаАутентификация` | Проверка Bearer/Basic |
| Общий модуль | `ИнтелбитРекаВебхуки` | Публикация исходящих событий |
| Общий модуль | `ИнтелбитРекаEnterpriseData` | Работа с регламентными обменами |
| Регламентное задание | `ИнтелбитРекаОтправкаВебхуков` | Фоновая отправка webhook-очереди |
| Регистр сведений | `ИнтелбитРекаОчередьВебхуков` | Буфер исходящих webhook-событий |
| Константа | `ИнтелбитРекаURL` | URL Рекa-сервера |
| Константа | `ИнтелбитРекаСекретWebhook` | Секрет HMAC |
| Константа | `ИнтелбитРекаКлиентID` | OAuth Client ID |

Все имена объектов начинаются с префикса `ИнтелбитРека` — конфликты с типовой конфигурацией исключены.
