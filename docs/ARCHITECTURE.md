## Поток данных

### Входящий (Фловеон → 1С)

1. Python-side `OneCHttpServiceClient` делает HTTP-запрос к опубликованному HTTPСервису.
2. Расширение обрабатывает запрос в `Module.bsl` нужного метода.
3. BSL-модуль вызывает методы типовой конфигурации через внутренний API.
4. Ответ форматируется через `ИнтелбитРекаОбщие.СформироватьУспешныйОтвет()` и возвращается.

### Исходящий (1С → Фловеон)

1. Подписки на события типовой конфигурации (в 4-17-12) вызывают `ИнтелбитРекаВебхуки.ОпубликоватьСобытие()`.
2. Событие записывается в регистр сведений `ИнтелбитРекаОчередьВебхуков`.
3. Регламентное задание `ИнтелбитРекаОтправкаВебхуков` (каждые 60 сек) вызывает `ОтправитьПакетСобытий()`.
4. BSL-код делает HTTP POST с телом JSON и заголовком `X-Signature: t=<unix>,v1=<HMAC-SHA256>`.
5. Python-side `OneCWebhookReceiver.verify_signature()` проверяет подпись и обрабатывает событие.

## Аутентификация

| Среда | Метод | Реализация |
|---|---|---|
| dev | HTTP Basic Auth | `ИнтелбитРекаАутентификация.ПроверитьBasicAuth()` |
| prod | Bearer JWT (OAuth 2.1) | `ИнтелбитРекаАутентификация.ПроверитьBearer()` |

## Версионирование исходников

Исходники хранятся в формате текстового экспорта 1С (`DumpConfigToFiles`). Для работы с репозиторием:

```bash
# Экспорт конфигурации в git
./scripts/dump-to-files.sh

# Импорт из git в конфигурацию
./scripts/load-from-files.sh
```
